Document Q&A Bot (RAG Application)
Overview

This project is a Retrieval-Augmented Generation (RAG) based Document Q&A Bot that allows users to ask questions about PDF documents.

The system extracts text from PDF files, splits the content into chunks, stores them in ChromaDB, retrieves relevant information based on user queries, and generates answers using Google's Gemini API.
Features
 - PDF Document Processing
 - Text Chunking
 - ChromaDB Vector Storage
 - Semantic Retrieval
 - Gemini-Powered Question Answering
 - Source Citations
 - Streamlit User Interface
Tech Stack
 - Python
 - Streamlit
 - ChromaDB
 - Gemini API
 - PyPDF
 - Python Dotenv
